# Brain map (context graph) — OpenHarness

This repo is a **portable harness** (patterns, `state/`, scripts). The **normative operator hub** for parser → JSON → API → UI, multi-root `CURSOR_STATE_DIRS`, and vault merges lives in the portfolio clone:

- **Portfolio hub:** sibling clone **`../MiscRepos/docs/BRAIN_MAP_HUB.md`** (parser → JSON → API → UI, multi-root env, REQ/AC).

**OpenGrimoire viewer:** run the MiscRepos `build_brain_map.py`, then open **`/context-atlas`** on the OpenGrimoire app (see OpenGrimoire `README.md` and `docs/OPENGRIMOIRE_SYSTEMS_INVENTORY.md` § Relationship to OpenHarness).

**Harness-only build:** [`../scripts/build_brain_map.py`](../scripts/build_brain_map.py) (minimal copy). For merges with MiscRepos + OpenHarness state in one graph, prefer **MiscRepos** `.cursor/scripts/build_brain_map.py` and env from **MiscRepos** `.cursor/brain-map.env.example`.
